Three multi-agent topologies, one causal-audit substitution point

At the marked handoff(s), the relayed cache is replaced with one of five conditions before the receiver continues
A. Sequential chain
Reasoner → Verifier → Finalizer. Each handoff is an independent audit point; same substitution condition applied at both.
B. Static fan-in
Two children process disjoint passage subsets; both children's KV substituted together before the merge (not one at a time).
C. Dynamic delegation (RLM+KV)
Only the spliced sub-call KV is audited; the root's own direct passage access is never touched, so zeroed/random never collapse to floor here.
Five substitution conditions applied at each ◯ audit point
real — correct cache, unmodified
dropped — nothing injected, receiver's own prompt only
zeroed — all-zero tensor, same shape
random — moment-matched noise
mismatched — real cache, wrong question
